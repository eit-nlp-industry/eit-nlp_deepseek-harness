# 人物识别

## 使用条件

出现下列情况时读取并执行本 skill：

- 当前任务需要确认画面中人物的身份；
- 无任务状态下，有人持续停留或表现出明确的互动意图；
- 需要判断当前画面里的人是否为已登记人员。

人物只是短暂经过、身份与当前任务无关、或没有任何互动价值时，不识别，直接 `observation_no_action`。

**不适用**：用户要求记住某人、修改某人资料时，不读取本技能，也不调用 `get_person_references`；记人属于另一个动作，直接使用记人工具。

## 执行流程

1. **确认对象**：当前画面里是否有明确、单一的识别对象。
2. **确认可辨识**：人脸是否足够清晰（不是背影、不是严重逆光、不是只露出局部）。
3. **多人时**：目标不明确就不自行选定一个人去认，先要求澄清或按无法确定处理。
4. **取参考**：调用 `get_person_references`（可按名字过滤，默认返回最近 3 位）。返回的参考照片会以图片形式附在本轮之后，每张前面标了 `person_id`。
5. **比对**：把当前画面的人脸与参考照片逐个比较。
6. **判定**：只有一个候选**明确匹配**时才确认身份；没有匹配、多个候选相似、参考图不清晰时，一律按陌生人或无法确定处理。
7. **行动**：根据当前任务与对话决定下一步——问候、询问、执行动作，或保持静默（`observation_no_action`）。

## 判断限制

- 不得仅凭衣服、位置、背景、身高、年龄、性别等非人脸特征确认身份。
- 不确定时不得猜名字，也不得说「你有点像某某」这类暗示性判断。
- 识别结果只是视觉判断，不能替代任务状态、工具返回或后台 Job 通知。
- 未经用户明确要求，不得调用 `remember_person`，不得新增、修改、删除人物资料。
- 不描述参考照片里的细节，不向用户解释比对过程。

## 连续观察

- 同一个人连续出现时，沿用最近一次可信的识别结果，不重复取参考图。
- 已问候过的人不重复问候；除非对方主动发起新的互动。
- 人物离开后又重新出现、或视觉证据明显变化时，才重新识别。

## 与用户沟通

- 认出：可以用一句话自然称呼对方，例如「某某，你遇到什么困难了吗？」；不解释是怎么认出来的。
- 陌生或不确定：不问姓名，只问是否需要帮助，例如「你好，有什么需要我帮忙的吗」。
- 不得说「你不是某某」「你不像已记录的人」这类话。

## 失败处理

- 人物库为空：按陌生人处理，不要假设身份，也不要把这件事当作错误反复报告。
- `get_person_references` 失败：说明无法核对身份，本轮按无法确定处理，不猜测。
- 参考图过期或缺失：按无法确定处理，等下一次观察。
