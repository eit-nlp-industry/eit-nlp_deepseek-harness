# 机器狗交互

## 适用范围

目前只覆盖握手。用户说「握个手」「伸手」「手给我」「击掌」等时按本 skill 执行。只做握手，不主动抓取、推拉或跟随。

## 一、取当前画面

- 只依据【环境观察】推进来的图片帧判断，不用记忆里的描述或想象补画面。
- 没有可用画面（最近一轮没有观察帧，或人不在画面里）：一句话请用户站到机器狗正前方、让机器狗看到手，然后结束本轮，等下一轮观察。
- 判断只用最新一帧；旧结论不沿用。

## 二、判断能否够到

逐条看画面里的证据：

1. **手在画面里**：能看见手掌/手臂，并且朝机器狗伸过来，不是垂在身侧。
2. **高度在可及范围**：手落在画面中部一带，和机器狗自身高度接近；手在画面上半部、人明显还是站姿时，机器狗够不到。
3. **距离够近**：手在画面里占的比例够大、细节看得清，没有被桌子、门框等挡住。

三条都满足才算「够得到」。看不清、只有背影或侧身、手被遮挡，一律按够不到处理，不要乐观假设。

一般规律：站着的成年人伸手通常高于机器狗的可及高度；蹲下后手落到画面中部、距离拉近才够得到。对方明显是儿童或本来就很矮时，不要机械要求蹲下。

## 三、够不到时

- 用一句自然的话请对方蹲下，并说明原因，例如「你太高了，麻烦蹲一点，我够不到你的手」。
- 只提要求，这一轮不调用握手工具。
- 结束本轮，等下一轮【环境观察】再判断，不要在同一轮反复催。
- 每轮最多提醒一次；连续两三轮画面没有改善时，改说具体一点：「再蹲低一点」或「往我这边靠一点」。
- 对方蹲下后回到第二节重新判断。

## 四、够得到时

1. 先给一句确认反馈，例如「好，可以了」。
2. 调用实际挂载的握手工具（工具目录里名称含 `handshake` / `shake` 的那个），参数按它的 schema 填；不要编造工具，也不要只描述动作。
3. 工具受理后一句话说明进展；失败时说明没完成及原因，不谎称已经握过。

## 五、边界

- 只做握手；不因为够得到就顺势抓取、拉人或让机器狗移动。
- 对方姿势异常、画面剧烈抖动、或手边有危险物品时先不动，说明当前不适合握手。
- 用户中途说「算了」「不用了」：立即停止，不再要求蹲下，也不再调用握手工具。
- 不把判断过程、坐标或画面细节讲给用户，只说结论和需要对方做的事。
