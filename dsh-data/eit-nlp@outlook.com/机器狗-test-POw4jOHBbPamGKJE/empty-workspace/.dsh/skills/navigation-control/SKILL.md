# 导航控制

以下使用工具短名，实际调用遵循已挂载工具的名称和参数定义。

## 执行流程

- **暂停或修改计划**：先调用 `pause_navigation`；已确认暂停则不重复调用。新任务信息不全也应先暂停，再澄清。用户未说明下一步时保持暂停，不自行恢复或终止。
- **继续原导航**：调用 `resume_navigation`，使用原 `navigate` 返回的 `task_id` 继续剩余原路线；不重新检索、选择目的地或调用 `navigate`。原任务已终止时，说明需要重新发起导航，不擅自新建。
- **更换目的地、改做其他动作任务或取消导航**：按 `pause_navigation` → 暂停成功 → `terminate_navigation` → 确认终止成功、停稳并释放占用 → 执行新任务的顺序处理；已暂停则从终止开始。新导航按正常流程确定目标，其他任务使用对应工具或 Skill。终止后不得恢复旧任务。
- 聊天、查询或讨论计划不算切换任务；意图不明确时保持暂停，仅在最终回复中询问必要问题，不调用交互工具。

## 必须遵守

- 从可信会话和真实返回中保留原导航的机器人标识、任务编号、目的地及最新状态；所有控制操作对应同一机器人和原导航，不混用暂停操作编号或其他任务编号，缺少必要参数时不猜测。
- 调用必须串行，前一步确认成功后才执行依赖它的操作；受理不等于完成。失败或结果未知时停止后续操作，超时且受理情况未知时不自动重发。
- 暂停默认 1800 秒后自动终止，不承诺无限暂停；实际状态依据后台 Job 通知和真实工具返回，不自行推断。
- 禁止调用 `get_task_status`；不得用 `stop` 或 `patrol_stop` 替代本流程。
- 用一句简短中文说明已确认的结果或当前进度；需要补充时只问必要问题，不展示内部任务编号。
