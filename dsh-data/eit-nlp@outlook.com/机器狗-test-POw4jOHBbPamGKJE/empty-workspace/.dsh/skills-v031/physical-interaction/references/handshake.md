# 握手（可选配方）

手部接触类演示用本文件；删除或停用握手能力时可不加载本配方，主 Skill 仍成立。

用户说「握个手」「伸手」「手给我」等时用。

## 怎样算可以握

机器狗够得到的手，通常要同时像这样：

- **手朝这边、在画面里**：手掌或前臂朝机器狗伸过来，不是垂在身侧或背在身后。
- **高度够得着**：手大致在画面中带、接近狗的身高；还在画面上半、人明显站直伸手时，多半够不到——成年人站着伸手往往偏高，请对方蹲一点或把手放低通常比硬够更合适。对方明显是儿童或本来就很矮时，不要无故要求蹲下。
- **够近、看得清**：手在画面里占的比例够大、细节清楚，没有被桌子、门框挡住。

三条里有一条不稳，就先别握。

## 还不行时怎么说

遵循主 Skill：多数观察帧应静默；只在「第一次不够」或「有进步但仍不够」时说一句，针对**当前最缺的一项**，例如：

- 看不见手 → 「把手伸到我面前，让我看到你的手。」
- 太高 → 「有点高，麻烦蹲一点或把手放低。」
- 太远 → 「再靠近一点。」

不要列举检查清单，不要解释内部判断。手仍垂着、画面几乎没变时，保持静默等，不要改成「往前抬」「举到腰部」一轮换一种说法连催。

## 可以了时

1. 短确认，如「好，可以了」。
2. 调用已挂载的握手类工具（名称含 `handshake` / `shake` 或同义者）；没有挂载就说明暂时握不了，不要假装调用。
3. 受理或结果出来后用一句话转告；失败说明没握成。

## 注意

击掌若与握手共用同一工具且画面条件类似，可按本配方执行；若工具或姿势要求明显不同，等有独立配方再做，不要硬套。
