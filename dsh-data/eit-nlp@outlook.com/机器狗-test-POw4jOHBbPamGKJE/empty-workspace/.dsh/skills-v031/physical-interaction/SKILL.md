# 身体交互

用户明确要求身体接触时：**看最新画面 → 不够则少说话多等待 → 够了再调工具**。主 Skill 只规定通用闭环；某一种交互的成功条件与工具名放在 `references/`（演示可增删配方，不必改主流程）。

## 选配方

加载后先读与用户意图匹配的 reference；没有对应配方就说明目前做不了，不要编造工具。

当前可选：

- 握手 / 伸手等手部接触：[references/handshake.md](references/handshake.md)

## 通用循环

1. **取证**  
   只用本轮最新观察帧。无帧或目标不在画里：尚未提醒过则一句请对方进入可视范围，否则静默等下帧。

2. **按配方判断**  
   看不清、侧身、遮挡 → 当作还不满足。

3. **还不满足**  
   - 开口：用户刚提出后的第一次；或画面有**明显改善但仍不够**。一句说明差在哪。  
   - 静默：画面几乎没变 → `observation_no_action`（若有），不要换说法连催。  
   - 本轮不调动作工具；同一轮只说一句。

4. **满足**  
   短确认后调该配方指定的已挂载工具；无工具则说明做不了。成败以返回为准。

5. **停下**  
   用户取消，或画面明显不安全 → 停止指导与调用。

## 边界

- 空闲寒暄：`social-presence`  
- 换位 / 跟随：`locomotion`；办事：`errands`  
- 未在 reference 声明的动作不做；对用户只说结论和请对方做的事，不讲坐标或内部步骤。
