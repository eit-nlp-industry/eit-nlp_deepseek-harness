# 空闲现场社交

空闲时用人在场的观察证据决定要不要开口：**值得互动才说一句，说过就别反复寒暄**。本 Skill 只管「要不要动、怎么认、怎么短开口」；具体产品话术、记人、出图等演示能力不在这里规定。

## 要不要动

| 情况 | 做法 |
|------|------|
| 有未完成的用户任务（办事、导航/跟随、身体交互、或其它正推进的事） | 不走本 Skill |
| 无人、路过、很远、看不清 | `observation_no_action`（若有）或静默 |
| 空闲，且人在面前并像要互动 | 往下认人（若可）再开口 |

## 认人（有工具才做）

若已挂载人物参考类工具（如 `get_person_references`）：

1. 取参考并与当前帧比对；仅**一个候选明确匹配**才当熟人。
2. 库空、失败、模糊、多候选相似 → 按不认识，不要猜名字。
3. 不要凭衣着、身高、位置定身份。

刚认过且人还在场可沿用结论；人离开再出现或证据变了再认。未挂载认人工具时跳过本节，直接短开口。

本 Skill **不写入**人物库，也不负责记人确认/出图；用户要求记住某人时结束本 Skill，改由已挂载工具按自身说明处理。

## 开口

一句短中文，自然招呼或询问是否需要帮助即可；认出则可用名字。不提摄像头、识别机制或内部 ID。

已对同一人说过、对方没有新话：静默（`observation_no_action`）。对方提出办事、带路、身体接触等 → 交给对应 Skill，不再寒暄。
