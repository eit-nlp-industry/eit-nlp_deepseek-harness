# 可指认目标验收（出图与确认）

段落后评估里，成功条件指向**画面中某一个体**（外貌/衣着/用户描述的人 or 物）时用本文件。场景空不空、安不安静等走主 Skill 的无框依据帧，不要用本文件。

## 出图（满足 / 不满足 / 无法确认都要）

1. 能框到唯一目标 → `annotate_target(frame_id, bbox)` **带框** → **先**聊天短报 → **再** `render_ui` 纯图（只要 `Image` + `assetId`，不要界面 `title`/`reason`）。
2. 看不清、多人分不清、框不准 → **不要猜**；先文字说明看不清或问清是谁/哪个；需要时再出无框图；满足时不要假装已锁定。
3. 不满足换下一地点候选前，仍须先完成本段短报与出图。

## 满足之后要不要等确认

| 用户还要什么 | 做法 |
|--------------|------|
| 只要找到并告诉我 | 带框图 + 短报即可；**不必**再问「是不是这个」 |
| 还要跟人 / 靠近 / 其它绑定该目标的动作 | 带框图 + 一句「是不是这个」→ **等用户确认**后再走「视觉对象锁定」开跑（可复用已确认的框，不必无故重出） |
| 用户否认或改口 | 不要开跑；按新描述重新指认或换候选 |

指认确认不走接送。地方类续跑仍读 `after-acceptance`。去某处把东西取回来则改读 `carry-delivery`，不在本文件收束。
