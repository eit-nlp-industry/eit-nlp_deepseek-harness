JSON 到底是什么？

一句话：它是一种用纯文本描述信息的格式，让不同的程序都能读懂同一份数据。

01 / 它不运行

它只是一段有格式的文字，本身不会做任何事。程序读到它，才知道该显示什么、保存什么。

02 / 它很直白

用 "键": 值 的配对来描述信息，像一张栏目清楚的登记表，看一眼就知道每一项是什么。

03 / 它会套娃

{ } 是一张表，[ ] 是一串清单。表和清单可以互相嵌套，装下复杂的信息。

一组键值对，就是一条信息

"姓名" 键 · 栏目名

"林小满" 值 · 填写内容

左边是“这项叫什么”，右边是“这项是什么”。多条信息之间，用逗号隔开。

键必须是双引号包起来的文字，比如 "姓名"。不写引号、用单引号都不行。

02

值可以是六种类型之一：字符串、数字、布尔值、null、数组、对象。

04

02

只有六种基本类型

记住这六种，你就能读懂绝大多数 JSON。每一种都配了最小示例和一句提醒。

字符串

string 01 
"你好，世界"

文字、句子、日期，甚至链接，都放进双引号里。

注意：单引号不是 JSON 的写法。

数字

number 02 
20
3.14
-5

整数、小数、负数都直接写，不加引号。

注意："20" 是文字，不是数字。

布尔值

boolean 03 
true
false

表示“是 / 否”“开 / 关”，只有这两个值。

注意：必须小写，不是 True。

空值

null 04 
null

表示“这里暂时没有内容”，是一个明确的空。

注意：它不等于 0，也不等于 ""。

数组

array 05 
["主题分享", "小组讨论", "自由交流"]

一串有顺序的值，像一张清单，用中括号包起来。

注意：项与项之间用逗号，最后一项不加。

对象

object 06 
{
  "楼": "图书馆",
  "楼层": 3
}

一组键值对，像一张小表，可以嵌套在其他值里。

注意：用大括号，键必须加双引号。

小提示 JSON 只有这六种类型。日期、颜色、文件、链接，通常都写成字符串，比如 "2026-11-14"。
03

把它们拼起来：一个完整例子

一份活动报名信息。左边是 JSON，右边是逐行翻译，对照着看一遍就懂了。

event.json JSON 
{
  "activity": "AI 如何改变学习",
  "date": "2026-11-14",
  "free": true,
  "capacity": 30,
  "location": {
    "building": "图书馆",
    "floor": 3
  },
  "topics": ["主题分享", "小组讨论", "自由交流"],
  "note": null
}
  • activity 活动名称字符串 · 用双引号包住文字
  • date 活动日期字符串 · JSON 没有专门的“日期”类型
  • free 是否免费布尔值 · true 表示“是”
  • capacity 名额上限数字 · 不加引号
  • location 地点对象 · 里面又套了两个字段
  • topics 活动环节数组 · 三项，有先后顺序
  • note 备注null · 暂时没有内容
04

三个最常见的错误

它们占了新手报错的绝大多数。每一条都给出错误示范、正确写法和原因。

错误 01

最后一项后面多了个逗号

逗号只用来“分隔”两项，不是“结束”一项。最后一项后面再加逗号，程序就会报错。

✕ 错误示范
{
  "name": "小明",
  "age": 18,
}
✓ 正确写法
{
  "name": "小明",
  "age": 18
}
错误 02

键名没加引号，或用了单引号

JSON 只认双引号，键和字符串都一样。单引号是 JavaScript 的写法，JSON 不接收。

✕ 错误示范
{
  name: '小明',
  age: 18
}
✓ 正确写法
{
  "name": "小明",
  "age": 18
}
错误 03

把注释写进了 JSON

JSON 不支持 // 或 /* */ 注释。想说明什么，就单独加一个字段，把话写进值里。

✕ 错误示范
{
  "name": "小明" // 学生姓名
}
✓ 正确写法
{
  "name": "小明",
  "note": "学生姓名"
}

05 / 发出前自检

花一分钟，对照这张清单

不用记语法，只要逐条看一遍，大部分低级错误都能提前发现。

  • 所有键都用双引号包起来了吗？
  • 所有字符串都用双引号包起来了吗？
  • 最后一项后面没有多余的逗号？
  • 大括号 { }、中括号 [ ] 都成对？
  • 没有注释、没有 undefined、没有函数？
  • 拿不准时，粘进任意 JSON 校验器看一眼？
JSON 不要求你聪明，只要求你把话说完整。
