# 财务费用与项目经费

飞书多维表格是唯一数据源，读写通过本会话的 `mcp__feishu__*` 工具完成。界面看本轮有没有 `render_ui`：有就只加载 `finance-form`，没有就只加载 `finance-text`。手册和规则里的「当前界面技能」指这一份。本技能不自己追问，也不自己出卡片。

## 数据源

账本只有这一份飞书多维表格。费用和项目不在工作区、会话目录或任何本地文件里。bash、读文件和搜索只用于用户刚刚交出的那一个文件，例如要上传的发票，或用户指定的 Excel。不要用它们去目录里找历史账，也不要因为工作区里有表格文件就把那份当成账本。

- base：`NnbxbUcP8a439PsErXncrAnkn6c`（财务费用报销管理）
- `项目预算表` `tblYHdK4DXS6SfvD` — 一个项目一条记录
- `费用清单表` `tbltFK7P9AwzGqvZ` — 一笔费用一条记录

直接用上面的 table id。读失败再 `bitableV1AppTableList`。本轮用 `bitableV1AppTableFieldList` 读一次字段和单选选项，后面复用。字段名和选项以这次读到的为准。规则和手册里的名称是在说明口径；和这次列表对不上时，用含义相同的线上字段，没有就停下来说明缺哪一项。不要沿用记得的旧选项，也不要现编。

## 三条硬规则

1. **确认后才写**：任何 create / update 都等当前界面技能拿到用户确认。有 `render_ui` 时，确认是表单提交。没有时，确认是 `finance-text` 的文字卡片。用户改哪一项，就只改那一项再确认一次。
2. **只写可写字段**：公式、自动编号、创建人、创建时间、修改人、查找引用一律不写。能不能写看本轮字段类型，不看记得的名字。当前这几项是公式或系统字段：`费用编号`、`共使用`、`实际到账金额`、`非项目收入`、`剩余金额`、`项目费用使用率`、`项目使用金额`、`非项目使用金额`、`状态`、`创建人`。
3. **不猜关键字段**：项目编号、经费来源、项目类型、金额、是否计入项目、钱的进出方向、启动资金算预算还是已到账。用户没说就不要填默认值。有 `render_ui` 时留空交给表单，不要先追问。没有 `render_ui` 时把缺的必填交给 `finance-text` 去问。单选只能用本轮字段列表里的选项。

口径和记账方向只在 `references/rules.md`。写之前读对应小节，不要另写一套。

## 四个动作

只读和本次意图对应的那一节。读完把事实交给当前界面技能。

## 出错时

- 找不到 `mcp__feishu__*` → 当前会话没挂财务 MCP，提示用户切到「财务管理」预设
- `99991672` → 应用缺权限，直接说明要开哪个 scope（`base:table:read` / `base:field:read` / `base:record:create`，上传附件再加 `drive:drive`），不要重试
- **单选写入会自动新增选项**：值不在现有选项里时，表单上写明「将新增选项：X」
- 写入被拒并提示选项不存在 → 不要重试，让用户先在表里加选项或把字段改成文本

## 工具边界

- 没有删除工具：要删费用时说明需要在多维表格里手动删除，不要把金额改成 0
- 没有批量工具：导入逐条写入，失败即停，并报告已写入条数
- `人员` 是文本，直接写姓名
- 票据附件用 `node <skill>/scripts/upload_media.mjs <文件路径>` 换 `file_token` 再写入
