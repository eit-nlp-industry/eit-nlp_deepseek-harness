# 财务文字确认

`finance-funds` 决定记什么、能不能写。本技能只在本轮没有 `render_ui` 时使用。预设用限制把这个工具拿掉，和会话里根本没有它，都算没有。有 `render_ui` 就改加载 `finance-form`，两份界面不要一起用。

手册和规则里的「当前界面技能」按这里做。那里写的「留空、不要先问」在这里改成：缺的必填先问。「用户确认后」指用户明确同意下面这张文字卡片，不是点头式的「好的」。不要调用 `render_ui`。

## 怎么呈现

- 查费用、经费概览、写入后的回显：直接用手册里的文字表。数字只用刚读到的值。
- 记费用、改费用、新建项目、发票确认、导入预览：先补必填，再出一张文字确认。用户同意后才按 `finance-funds` 写入。

## 缺字段时

必填还空着，用一次 `ask_user_question` 把缺的项问完，再出确认卡片。不要先写入。费用至少要有项目、金额、付款方向、是否与项目相关。新建项目至少要有名称、项目编号、经费来源、项目类型，以及启动资金是预算还是已到账。

选择项用这些真实选项，不要现编：

| 字段 | 选项 | 已经能确定时 |
|---|---|---|
| 项目 | `项目预算表` 里的项目。0 条命中时加上「新建：<用户说的名字>」 | 只命中 1 条就用全名，不必再问 |
| 经费来源 | IDT、EIT | 用户没说就问 |
| 项目类型 | 横向、纵向 | 用户没说就问 |
| 费用类型 | 本轮读到的线上选项 | 用户没说就问，不要默认成「其他」 |
| 是否与项目相关 | 是、否 | 用户没说就问 |
| 付款方向 | 支出、收入、支出冲销、收入退回 | 能对上 rules §2.0 就用那一行，不必再问 |
| 启动资金 | 预算、已到账 | 用户没说就问 |

人员、金额、说明、项目编号、申请日期知道就写上，不知道就放进同一次提问。相对日期先换成具体日期。新的单选值要在确认里写「将新增选项：X」。

## 确认卡片

必填齐了，先出卡片，停下来等用户确认。余额用刚读到的 `剩余金额` 现算。没有的行不写。

```
记一笔费用
- 项目：
- 人员：
- 申请日期：
- 费用类型：
- 付款方向：
- 是否与项目相关：
- 说明：
- 余额：当前剩余 → 记完后的剩余
- 将新增选项：
- 将上传附件：
```

用户确认后才写入。用户改某一项，只改那一项，再出一次卡片。改项目或新建项目时，卡片改成对应字段，仍是先确认再写。
