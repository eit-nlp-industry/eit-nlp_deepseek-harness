# runtime —— 已确认方案快照

`plan_save` 把每次最终确认的活动方案写成 Markdown 文件放到这里，文件名格式：

```
<UTC 时间戳>-<ascii slug>.md      例：20261113-012403-plan.md
```

文件内容以 `# <方案标题>` 开头，随后是保存时间、编号，再下面是完整方案正文。

## 调取方式

在「校园活动筹备助手」会话里直接说：

- 「看看之前保存的方案」→ 助手调用 `plan_list` 列出编号
- 「打开 20261113-012403-plan」→ 助手调用 `plan_get` 读取全文

## 说明

- 快照不会随对话继续更新；改方案要重新确认并再保存一次。
- 目录可手工备份或迁移；删除文件不影响预设本身。
- 由 Host 插件直接写盘，不受会话 workspace 写权限限制。
