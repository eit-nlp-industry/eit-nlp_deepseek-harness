## 三、关键问题与处理

| 问题 | 根因 | 处理 | 状态 |
|---|---|---|---|
| 表单「保存并继续」点了没反应 | 按钮 `eventName` 被写成自定义名，客户端只认 `form.submit` | 固定按钮参数为 `{"action":"form.submit","params":{"eventName":"form.submit"}}` | ✅ 已验证 |
| 方案下拉偶尔为空、无法选择 | `rich_content` 下 `DynamicForm select` 会偶发丢 `options` | 选择类步骤改走 `generic_pick_one`；卡片禁用 select | ✅ 已验证（选非默认项可回传） |
| 预设在新会话里消失 | 把 `plan-store` 写成 preset 子插件，导致预设注册卡住 | 移到 profile 级插件行 | ✅ 已验证 |
| `plan_save` 插件报 `cannot get property "tools"` | 未声明 `inject: ['tools']` | 补 `export const inject = ['tools']` | ✅ 已验证 |
| `plan_list` 把 README 当方案 | 列举未按文件名过滤 | 只匹配 `<时间戳>-<slug>.md` | ✅ 已验证 |
| 最终确认要点三轮 | 提示词把确认/保存/展示拆成多轮 | 改为同轮一次性完成 | ⏳ 待预设会话验证 |
| 原环境 `node_modules` 被误清空 | pnpm 在脚本前自动安装、自身 worker 缺失导致中断剪枝 | 立即停止操作、评估影响；运行中服务未受影响；后续静态核查显示已基本恢复 | ⚠️ 重启完整性未验证 |
