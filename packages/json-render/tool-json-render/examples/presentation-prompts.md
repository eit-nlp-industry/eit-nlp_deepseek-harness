# 呈现选型试用输入

使用更新后的部署，在普通预设中新建会话。除多轮示例外，每个输入单独测试；也可换一个新建预设重复。输入不指定组件名称，以观察公共规范是否在选型前生效。表中的预期用于人工核对，不要一同粘贴进对话。组件生成与业务保存是否成功分别记录。

|编号|观察目标|预期呈现|
|---|---|---|
|1|短答是否保持简洁|文字|
|2|二选一是否轻量|可用的原生选择|
|3|整单预填、核对及修改|动态表单|
|4|自主分类浏览|分组切换与按需展开|
|5|直接调整顺序|可操作的排序组件；未接通时说明限制|
|6|多按钮及回传|有处理器的按钮，或操作选择字段加已接通提交；保留最新值|
|7|同一任务按阶段切换|咨询用文字，整单编辑用表单，回执回到文字|

## 1. 简短说明

```text
用不超过三句话解释：会议纪要和会议录音分别适合在什么时候使用？
```

核对：回答直接，不为短答生成表单、选项或复杂卡片。

## 2. 简单选择

```text
我们准备安排一次项目复盘，两个时间都可以：周三15:00或周四10:00。请先让我选一个，只收集我的选择，暂不创建日程。
```

核对：优先原生选择；未选前不把推荐项当作确认，不提前创建日程。

## 3. 复杂预约草稿

```text
请帮我做一份可以核对和修改的会议室预约草稿，只演示填单，不做真实预约。已知信息：主题“季度产品复盘”；日期2026年12月10日；时间14:00—16:00；人数12人；会议室候选“大会议室A”“讨论室B”；需要投影仪、白板；联系人林晓；联系电话13800000000；备注“需要远程参会”。请预填已知信息，让我集中修改后提交草稿。
```

核对：有整单编辑及明确提交入口；候选项来自输入。将联系人改成陈晨后再提交，检查回传是陈晨，其他字段未丢失。草稿回传不代表预约成功。

## 4. 分类浏览

```text
我要浏览公司的三类常见问题，希望自己切换分类，并按需展开答案。账号类：忘记密码可在登录页重置，账号锁定需联系管理员；报销类：差旅需提供行程和发票，餐费需提供发票及事由；设备类：电脑故障先登记现象，借用显示器需填写归还日期。请把这些资料整理成适合反复查看的内容，不需要我提交信息。
```

核对：分类切换、展开后有真实内容；不因出现“填写”一词就弹业务表单，不额外创造报销政策。

## 5. 调整顺序

```text
我在试排一次展会参观顺序。现有四个展位：P1“机器人”、P2“储能”、P3“医疗设备”、P4“工业软件”。请让我直接调整顺序，核对后把完整的新顺序交回对话。这里只调整清单，不规划真实路线、不预约展位。
```

核对：若接口支持排序应用，应能返回完整顺序与P1—P4稳定标识；不只改变显示序号，不声称已经修改外部行程。

## 6. 确认、跳过与继续新增

```text
请收集活动物资登记草稿：物资名称、数量、用途、联系人、备注。先预填一条：名称“折叠椅”、数量20、用途“签到区”、联系人“林晓”。我希望能选择确认本条、跳过本条，或接收本条后继续新增。请使用当前确实能响应的操作方式，只在对话中收集草稿，不写入真实库存系统。
```

核对：允许采用“操作选择项＋一个提交按钮”，不以独立按钮数量判断好坏。改数量为25、联系人为陈晨后测试确认及继续新增；检查操作选择、最新字段和草稿范围。另开一次测试清空字段后跳过：没有绕过校验能力时应采用可用原生选择，不补造字段；结果未知时不清空草稿。

## 7. 多轮阶段切换

第一轮：

```text
我们公司准备收集访客登记草稿，所需信息包括姓名、来访日期、到访时段、人数、拜访对象和备注。先只解释这些信息分别用来做什么，暂时不要让我填。
```

第二轮：

```text
现在帮我填写并核对整单，只收集草稿，不做真实预约。姓名王宁，日期2026年12月11日，时段上午10:00—11:00，人数3人，拜访对象产品团队，备注“携带演示设备”。请让我修改后提交。
```

提交后，第三轮：

```text
请用一句话说明刚才实际完成到哪一步，还有没有正式预约结果。
```

核对：咨询阶段文字、整单阶段动态表单、结果阶段简短文字。已有按钮完成同次确认后不重复弹确认；准确区分草稿已接收和正式预约结果。
