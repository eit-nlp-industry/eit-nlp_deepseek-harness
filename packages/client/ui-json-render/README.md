# @deepseek-ai/dsh-client-ui-json-render

English | [中文](README.zh.md)

## Summary

Show the latest successful `render_ui` result as the final answer or alongside its prose. A later failed render removes the earlier card and preserves the written answer. The tool row stays a short status. A form submit is queued as the next user message.

## Use this package

Add the package to the Web client composition. A successful display declared with `answer_presentation: replace` replaces a completed closing response containing one text block and optional reasoning. Missing, malformed, unsupported, or failed render results preserve the written answer. Rendering exceptions restore the original Markdown with its links and controls. The written answer remains in the Session for copying and export. Supplementary displays, forms, historical results without an explicit declaration, and responses with other block layouts render under the prose. The tool row only reports status.

Base and forms results use the stable Ant Design registry. A rich profile diagnostic uses the public experimental registry, which includes Image and ImageUpload. Upload targets come from host adapters; the payload only names `uploadTarget`. A Vue host uses the Vue adapter from the same v0.2.0-rc.5 release instead of these React components. The renderer maps Ant Design CSS variables to the host's semantic theme tokens. Every payload has a rounded, elevated surface, including layouts rooted in Stack or DynamicForm; a root Card or bordered Section shares that surface without a second frame. Cards, tables, metrics, steps, notices, and form controls follow the host's light/dark palette and font settings. Form labels sit above their controls; fields retain their natural height, and card content has explicit gaps. Dropdowns stay inside the themed surface, and wide tables scroll independently. Grids stack on narrow screens; reduced-motion preferences disable local animation. Styling is local to this renderer and requires no changes to stored payloads or the render server.

## Model Experience

Indirectly, through the host `render_ui` tool, which owns the model-facing text.

#### KV Cache effect

The row only reads a recorded tool result and does not change the prompt prefix.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- Knowledge-base business components are not generated by the current server. Relative Image `src` values are requested from the Web host and must already be paths that host serves.
