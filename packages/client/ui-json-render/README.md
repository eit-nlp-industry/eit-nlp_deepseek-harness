# @deepseek-ai/dsh-client-ui-json-render

## Summary

Show the last successful `render_ui` payload at the end of the final answer. The tool row stays a short status. A form submit is queued as the next user message.

## Table of Contents

- [Use this package](#use-this-package)

<a id="use-this-package"></a>
## Use this package

Add the package to the Web client composition. A successful `render_ui` payload renders under that turn's closing answer. The tool row only reports status.

<a id="model-experience"></a>
## Model Experience

Indirectly, through the host `render_ui` tool, which owns the model-facing text.

#### KV Cache effect

The row only reads a recorded tool result and does not change the prompt prefix.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- The row renders the stable base and forms catalogs. Knowledge-base business components are not generated by the current server.
